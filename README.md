
                   quiz                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                         
  A Java/Swing framework for building knowledge quizzes from structured data, plus a workbench for generating new quiz domains from Wikidata.                                                                                            
                                                                                                                                                                                                                                         
  Overview                                                                                                                                                                                                                               
                                                                                                                                                                                                                                         
  Everything in the app is a Quizable — an object with a stable identifier, a display name, and reflectively-described fields. Two things are built on top of that contract:                                                             
                                                                                                                                                                                                                                         
  1. A quiz engine. Quizables support set operations (field projection, unique-combination generation, identity), which drive several quiz formats — multiple-choice, categorize, intersection, pairs, and a six-degrees connection game 
  (shortest path over a Quizable graph via JGraphT).                                                                                                                                                                                     
  2. A reflective UI. Any Quizable renders as a searchable, sortable card via QuizablePanel, with no per-type UI code. Cards are drawn by lightweight custom-painted components (not per-field Swing widgets), so they stay cheap even   
  with tens of thousands of fields. Field behaviour is controlled by annotations in quiz.annotations (@QuizableReference, @QuizableInline, @Link, @MinorField, @NotQuizableField); nested objects show as collapsible chips that         
  expand/collapse in place, and text/links support selection and copy.                                                                                                                                                                   
                                                                                                                                                                                                                                         
  Ships with hand-built knowledge sets (flags & coats of arms, world states, languages, Oscar/Nobel data, presidents, mythology, …) and the tooling that produced them.                                                                  
                                                                                                                                                                                                                                         
  Wikidata explore workbench                                                                                                                                                                                                             
                                                                                                                                                                                                                                         
  wikidata.explore is a Swing workbench (ModelBuilderFrame) that turns a Wikidata class into a working Quizable domain:                                                                                                                  
                                                                                                                                                                                                                                         
  - Query Wikidata (SPARQL + MediaWiki API) through a generic query → execute → parse → sink workflow with a live, structured query log.                                                                                                 
  - Profile a class's properties (sampling, property scoring, cardinality detection) to suggest fields and types.                                                                                                                        
  - Generate Java Quizable classes for the modelled class at runtime (in-memory compilation), extract instances from Wikidata, and materialize them — all tracked as a reproducible GenerationRun (plan → extract → compile →            
  materialize).                                                                                                                                                                                                                          
                                                                                                                                                                                                                                         
  Tech                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                         
  - Java 21, Swing, Maven                                                                                                                                                                                                                
  - JGraphT (graph quizzes), Jackson (JSON), jsoup (HTML), Apache Batik (SVG flags), Tess4J/OpenCV (image work), Byte Buddy
